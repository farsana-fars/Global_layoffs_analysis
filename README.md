# Global_layoffs_analysis
## 📌 Project Overview

This project analyzes global layoffs data from 2020 to 2023 to identify trends
across companies, industries, countries and time periods.

## 🛠️ Tools Used

- SQL
- Power BI
- Excel

## 🔄 Project Workflow

1. Data cleaning using SQL
2. Exploratory data analysis
3. Data transformation
4. Power BI visualization
5. Dashboard creation
6. Business insights

## 🔍 Key Insights
-Layoffs peaked in 2022 at approximately 67K employees before declining in 2023.
-Retail was the most affected industry, while the United States accounted for the largest share of layoffs. 
-Amazon recorded the highest layoffs among the companies analyzed. Across 474 companies, approximately 139.79K employees were laid off, with an average layoff rate of 22.5%.
-The funding analysis also revealed substantial variation, with most companies showing relatively low layoffs and a small number of highly funded companies emerging as major outliers
